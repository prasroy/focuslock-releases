# FocusLock releases

Installers for **FocusLock**, a calm focus and study app for Windows by [Reflect & Build](https://reflectandbuild.com).

**Download:** [reflectandbuild.com/download](https://reflectandbuild.com/download). The website picks the right installer for your PC.

This repository only hosts release files and release notes. The app's source code is private.

| Your PC | File |
|---|---|
| Most Windows PCs (Intel or AMD) | `FocusLock-<version>-x64.msi` |
| ARM-based PCs (for example Snapdragon / Copilot+ PCs) | `FocusLock-<version>-arm64.msi` |

To check, open **Settings → System → About** and look at **System type**.

- **Requirements:** Windows 10 version 2004 (build 19041) or later, or Windows 11. No admin rights needed; FocusLock installs for your account only.
- **Early access builds are not code-signed yet**, so Windows SmartScreen may say "Windows protected your PC". Select **More info → Run anyway**. The Microsoft Store version (coming soon) is signed by Microsoft.
